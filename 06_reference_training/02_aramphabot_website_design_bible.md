# Aramphabot Website Design Bible

## Core Identity

Aramphabot Studio is not a generic design office. It is a context-driven architecture and interior design studio focused on atmosphere, narrative, proportion, material, and sensory experience.

The website must express the studio as:
- Thoughtful
- Precise
- Calm
- Premium
- Human
- Contextual
- Architectural
- International in standard
- Local in sensitivity
- Practical for real clients

## Core Website Concept

The website should feel like a calm architectural journey.

Visitors should feel that Aramphabot Studio understands:
- Place
- Light
- Shadow
- Climate
- Material
- Human experience
- Hospitality value
- Commercial value
- Memory and atmosphere

## Design Keywords

- Quiet luxury
- Context-driven architecture
- Architecture of memory
- Spatial storytelling
- Hospitality sensibility
- Warm minimalism
- Editorial calm
- Material atmosphere
- Refined proportion
- Sensory experience
- Thai contemporary sensitivity
- Boutique global practice

## Homepage Direction

The homepage should not feel like a sales landing page.

It should feel like entering a calm architecture publication.

Required feeling:
- Large hero image
- Short memorable headline
- Quiet but confident studio statement
- Featured projects with strong image presence
- Clear design philosophy
- Services shown with restraint
- Journal or insight preview
- Contact CTA that feels calm and professional

Recommended homepage flow:
1. Hero image and headline
2. Short studio manifesto
3. Featured projects
4. Design philosophy
5. Services overview
6. Process preview
7. Journal preview
8. Contact CTA

## Homepage Hero Rules

Hero section should be:
- Large
- Image-led
- Calm
- Not crowded
- Strong in atmosphere
- Clear in message

Suggested headline:
Architecture of Place, Memory, and Quiet Experience.

Suggested subheadline:
Aramphabot Studio creates architecture and interiors shaped by context, narrative, material sensitivity, and the emotional rhythm of space.

Avoid:
- Too many buttons
- Too much intro text
- Generic welcome messages
- Cliché corporate phrases

## Projects Page Direction

Projects should be the heart of the website.

The Projects page should feel like an architecture archive:
- Clean grid
- Large images
- Minimal but clear metadata
- Filter by project type
- No clutter
- No excessive text on cards

Each card should show:
- Project title
- Location
- Year
- Type
- Short description

Project categories:
- Hospitality
- Residential
- Commercial
- Interior
- Concept
- Development Study

## Project Detail Direction

Each project detail page should read like an editorial architecture feature.

Recommended structure:
1. Hero image
2. Project title and facts
3. One-sentence concept
4. Site and context
5. Design narrative
6. Spatial sequence
7. Key design moves
8. Material and atmosphere
9. Client value
10. Gallery
11. Related projects
12. Contact CTA

## About Page Direction

The About page should build trust and identity.

It should include:
- Studio origin
- Design philosophy
- What makes the studio different
- Values
- Team / founder placeholder
- Type of clients served
- Why the studio matters

Tone:
- Professional
- Warm
- Confident
- Not arrogant
- Not too corporate

## Services Page Direction

Services should be clear enough for real clients.

Each service should answer:
- What is it?
- Who is it for?
- What does the client receive?
- Why does it matter?

Core services:
- Architecture Design
- Interior Design
- Hospitality Design
- Commercial Design
- Residential Design
- Feasibility & Concept Strategy
- Spatial Brand Experience
- Visualization Direction

## Process Page Direction

The Process page should reassure clients.

It should make the studio feel systematic, thoughtful, and easy to work with.

Recommended steps:
1. Discovery & Brief
2. Site & Context Analysis
3. Concept Strategy
4. Schematic Design
5. Design Development
6. Visualization & Presentation
7. Construction Documentation
8. Coordination & Site Support

## Typography

Typography should be:
- Elegant
- Calm
- Editorial
- Highly readable
- Spacious
- Confident

Use large headlines with restrained body copy.

Avoid:
- Overly playful fonts
- Tech startup font feeling
- Too many font weights
- Tiny unreadable text
- Too much uppercase

## Color

Use:
- Warm ivory
- Limestone
- Sand
- Warm gray
- Charcoal
- Muted bronze
- Deep brown
- Soft stone

Avoid:
- Neon
- Bright corporate blue
- Overuse of pure black
- Random gradients
- Loud accent colors
- Heavy gold luxury clichés

## Motion

Motion should be subtle and architectural.

Allowed:
- Soft fade
- Gentle reveal
- Smooth hover
- Slow image transition
- Subtle menu transition

Avoid:
- Bouncy animation
- Excessive parallax
- Flashy effects
- Overly complicated scroll behavior
- Animation that slows the website

## Content Tone

Writing should feel:
- Professional
- Poetic but clear
- Architectural
- Trustworthy
- Calm
- Not exaggerated

Avoid:
- “We are the best”
- “No.1 architecture firm”
- Fake awards
- Fake client claims
- Overly sales-heavy copy
- Empty luxury words

## Good Writing Example

A shaded arrival sequence leads guests from the street into a quieter interior world, where filtered light, warm surfaces, and framed views create a slower rhythm of experience.

## Bad Writing Example

This amazing world-class masterpiece creates an unforgettable magical lifestyle for everyone.

## Final Design Goal

The website should make a serious client think:

“This studio has taste, discipline, and the ability to turn architecture into a meaningful experience.”
