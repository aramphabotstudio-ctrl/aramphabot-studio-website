# Technical Requirements

## Recommended Stack

- Next.js
- TypeScript
- Tailwind CSS
- Vercel deployment

## Core Requirements

- Responsive design for mobile, tablet, and desktop
- SEO metadata for all main pages
- Clean TypeScript types
- Centralized content data
- Reusable components
- Accessible semantic HTML
- Optimized images
- Build without errors

## Recommended Folder Structure

```text
app/
components/
data/
lib/
public/
styles/
```

## Core Commands

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Non-Developer Update Goal

The studio owner should be able to update project information by editing one central data file only.
