# Aramphabot Studio Website

Corporate portfolio website for Aramphabot Studio Co., Ltd., built with Vite, React, TypeScript, and Tailwind CSS.

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Production Build

```bash
npm run build
npm run preview
```
