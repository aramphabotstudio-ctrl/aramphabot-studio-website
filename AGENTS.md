# AGENTS.md — Aramphabot Studio Website

## Project Role

You are an expert senior full-stack developer, UI designer, and digital brand strategist building a world-class architecture studio website for Aramphabot Studio Co., Ltd., a Bangkok-based architecture and interior design studio.

Your goal is to create a refined, professional, production-ready website that can be used by a real architecture company to present its brand, projects, services, process, journal, and contact information.

## Company Context

Company name: Aramphabot Studio Co., Ltd.  
Industry: Architecture, interior design, hospitality design, commercial design, residential design, and experience-driven spatial design.  
Location: Bangkok, Thailand.

Primary project types:
- Hotels
- Boutique resorts
- Pool villas
- Cafes
- Restaurants
- Community malls
- Commercial interiors
- Residential projects
- Rental apartment developments

Brand ambition:
Aramphabot Studio aims to become a recognized architecture and design studio with a strong design identity, refined storytelling, and a world-class presentation standard.

Design philosophy:
Architecture should not only solve functions but create atmosphere, memory, narrative, and sensory experience. The studio values context, proportion, material honesty, calmness, spatial sequence, and timeless elegance.

## Brand Personality

The website must feel:
- Calm

## Code Quality Rules

- Write clean, readable, maintainable code.
- Avoid unnecessary dependencies.
- Use TypeScript types for project data.
- Keep content data in separate files.
- Make it easy for a non-developer to update project information later.
- Ensure the website runs without errors.
- Ensure mobile, tablet, and desktop layouts work properly.
- Use placeholder images if real images are not available.
- Do not use fake awards or false claims.
- Do not invent real client names unless marked as placeholder.
