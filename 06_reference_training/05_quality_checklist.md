# Aramphabot Website Quality Checklist

Before finishing any website task, Codex must check the following.

## 1. Brand Fit

- Does the website feel like an architecture studio?
- Does it feel premium and calm?
- Does it avoid generic template feeling?
- Does it communicate atmosphere and context?
- Does it feel suitable for hospitality, villa, cafe, restaurant, and boutique commercial projects?
- Does it avoid fake claims?
- Does it feel like Aramphabot Studio, not a copied reference?

## 2. Reference Strategy Fit

- Is the hospitality storytelling strong enough? 60% K-Studio principle
- Is the mood calm, tactile, and warm minimal? 20% Norm principle
- Is there Thai contemporary sensitivity? 10% PHTAA principle
- Is the information architecture professional and trustworthy? 10% Foster principle
- Are all references used as principles only, not copied directly?

## 3. Visual Quality

- Is the spacing generous?
- Is typography elegant and readable?
- Are images treated as primary content?
- Are project cards refined?
- Is the color palette warm and restrained?
- Is mobile layout beautiful?
- Are buttons quiet and premium?
- Is the footer refined?
- Does the site avoid loud animation?

## 4. Content Quality

- Is the writing clear?
- Is the tone professional?
- Is the language not exaggerated?
- Are project stories structured well?
- Are services easy for clients to understand?
- Is the process page reassuring?
- Does the contact page encourage serious inquiries?
- Are all claims safe and verifiable?

## 5. Project Storytelling Quality

For each project detail page:

- Is the concept clear?
- Is the site/context explained?
- Is the spatial sequence explained?
- Are materials and atmosphere described?
- Are key design moves listed?
- Is client value explained?
- Does the page feel like an editorial architecture feature?

## 6. Technical Quality

- Does the website build successfully?
- Are there TypeScript errors?
- Are there lint errors?
- Are links working?
- Is navigation consistent?
- Is metadata added?
- Are images handled gracefully?
- Is the project data easy to edit?
- Is the folder structure clean?
- Are components reusable?

## 7. SEO Quality

- Does each page have title and description?
- Is heading structure clear?
- Are image alt texts descriptive?
- Are architecture-related keywords used naturally?
- Is there no keyword stuffing?
- Is Open Graph metadata included where appropriate?

## 8. Mobile Quality

- Is the hero readable on mobile?
- Are project cards beautiful on mobile?
- Is the menu easy to use?
- Are contact form fields easy to tap?
- Are font sizes readable?
- Is spacing still premium?

## 9. Final Required Checks

Run:

```bash
npm run build
```

If available, also run:

```bash
npm run lint
```

If any check fails, fix the issue before final response.

## 10. Final Response Required from Codex

Codex must report:

1. Summary of improvements
2. Files changed
3. Build result
4. Lint result if available
5. Remaining placeholders
6. Recommended next steps
