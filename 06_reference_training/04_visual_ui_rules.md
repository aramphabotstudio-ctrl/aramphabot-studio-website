# Visual UI Rules for Aramphabot Studio Website

## Overall UI Direction

The website should feel:
- Calm
- Editorial
- Architectural
- Premium
- Warm
- Minimal
- Image-led
- Trustworthy

It should not feel:
- Generic
- Loud
- Cheap
- Trendy for no reason
- Like a SaaS landing page
- Like a template portfolio

## Layout

Use:
- Large white space
- Strong grid
- Editorial section spacing
- Clear page hierarchy
- Image-first composition
- Balanced asymmetry where appropriate
- Calm rhythm between text and images

Avoid:
- Crowded sections
- Too many cards per row on desktop
- Overuse of boxes and borders
- Generic SaaS layout patterns
- Too many centered sections
- Overly dense content blocks

## Page Width

Use generous max-width rules.

Suggested behavior:
- Text sections should be narrower for readability
- Image grids can be wider
- Hero sections can be full width
- Project detail pages should alternate between image-led and text-led sections

## Header

The header should be:
- Minimal
- Calm
- Easy to read
- Sticky only if elegant
- Not too tall
- Not visually heavy

Navigation:
- Work
- Studio
- Services
- Process
- Journal
- Contact

Avoid:
- Too many menu items
- Big colorful buttons in header
- Heavy drop shadows
- Loud hover effects

## Footer

The footer should feel premium and architectural.

Include:
- Studio name
- Short positioning statement
- Contact
- Social links
- Navigation
- Copyright

Footer tone:
- Quiet
- Clear
- Spacious
- Trustworthy

## Project Cards

Project cards should be refined.

Rules:
- Large image area
- Minimal text
- Clear metadata
- Elegant hover
- No loud badges
- No heavy shadows
- No cheap card effect
- Maintain consistent image ratios

Card information order:
1. Project image
2. Title
3. Location / Year / Type
4. Short description

## Buttons

Buttons should be quiet.

Use:
- Text buttons
- Underline hover
- Minimal border buttons
- Muted bronze or charcoal accent

Avoid:
- Large colorful CTA buttons
- Rounded SaaS pill buttons
- Excessive shadows
- Flashy gradient buttons

## Images

Images are the most important visual asset.

Rules:
- Use large images
- Maintain consistent aspect ratios
- Avoid distorted cropping
- Use neutral placeholders when no image exists
- Use descriptive alt text
- Let images breathe with enough spacing

Image mood:
- Warm daylight
- Natural materials
- Quiet composition
- Architecture as subject
- Minimal styling

## Typography Scale

Use a clear typographic scale.

Recommended hierarchy:
- Hero headline: large, elegant, memorable
- Section titles: calm and clear
- Body text: readable, restrained
- Captions: small but not tiny
- Metadata: precise and quiet

Avoid:
- Too many sizes
- Too much bold text
- Too much uppercase
- Decorative fonts

## Color Use

Main background:
- Warm ivory or soft stone

Text:
- Charcoal or deep warm gray

Accent:
- Muted bronze, taupe, or deep brown

Use color sparingly.

## Mobile

Mobile must feel premium, not compressed.

Rules:
- Generous spacing
- Readable font sizes
- Clear menu
- Project images remain strong
- Avoid tiny metadata
- Keep CTAs easy to tap
- Avoid complex multi-column behavior

## Accessibility

Use:
- Semantic HTML
- Proper heading order
- Alt text
- Keyboard-friendly navigation
- Sufficient color contrast
- Visible focus states

## Performance

Avoid:
- Large unoptimized images
- Too many animation libraries
- Heavy background videos by default
- Unnecessary dependencies

## Final UI Test

The website should pass this test:

If all logos and text were removed, the layout should still feel like an architecture studio, not a generic business template.
