# Project Page Storytelling Rules

## Purpose

Every project page must tell a story, not just display images.

Aramphabot Studio projects should be described through:
- Site
- Context
- Arrival
- Light
- Material
- Atmosphere
- Program
- Human experience
- Memory
- Spatial sequence
- Client value

## Project Story Formula

For each project, use this structure:

### 1. Project Premise

Explain:
- What is the project?
- Where is it?
- What type of project is it?
- Who is it for?
- What was the main challenge or ambition?

### 2. Site and Context

Describe:
- Location
- Climate
- Surrounding condition
- View
- Noise
- Street condition
- Landscape
- Cultural context
- Market context if relevant

### 3. Design Intention

Explain the central design idea in one clear sentence.

Example:
The project is conceived as a quiet sequence of shaded thresholds, warm surfaces, and framed views.

### 4. Spatial Sequence

Explain how people move through the project:
- Arrival
- Threshold
- Main space
- Transition
- Private zone
- Viewpoint
- Ending moment

A project should feel like a sequence, not only a set of rooms.

### 5. Material and Atmosphere

Describe:
- Material palette
- Light quality
- Texture
- Color
- Shadow
- Thermal feeling
- Mood
- Sensory experience

### 6. Key Design Moves

List 3–6 important design decisions.

Example:
- A compressed arrival sequence opens into a calm courtyard.
- Deep overhangs filter tropical light.
- Warm stone and timber create a quiet hospitality atmosphere.
- The facade is layered to balance privacy and openness.

### 7. Client Value

Explain how the design helps the client:
- Stronger identity
- Better guest experience
- Better market positioning
- More memorable space
- Functional clarity
- Operational efficiency
- Long-term brand value

### 8. Editorial Closing

End each project story with a short statement that connects space, atmosphere, and value.

Example:
Rather than presenting luxury as decoration, the project creates value through calmness, sequence, and the emotional memory of arrival.

## Page Structure for Project Detail

Recommended order:

1. Hero image
2. Title and metadata
3. Concept statement
4. Project overview
5. Site and context
6. Design narrative
7. Spatial sequence
8. Key design moves
9. Material and atmosphere
10. Gallery
11. Related projects
12. Contact CTA

## Metadata to Include

Each project should include:
- Project name
- Location
- Year
- Status
- Type
- Scope
- Area
- Team / role if available
- Photography credit if available

## Writing Rules

Write with clarity and restraint.

Do not over-explain.
Do not use empty poetic words.
Every poetic sentence must connect to a spatial or material idea.

Good:
A shaded entry compresses the arrival before releasing guests into a courtyard of filtered light.

Bad:
This project creates a magical world of unforgettable dreams and endless beauty.

## Avoid These Words Unless Supported by Real Evidence

Avoid:
- Iconic
- World-class
- Masterpiece
- No.1
- Award-winning
- Luxury beyond imagination
- Landmark
- Revolutionary

Use instead:
- Calm
- Refined
- Contextual
- Layered
- Tactile
- Atmosphere-led
- Hospitality-focused
- Material-sensitive
- Spatially clear

## Project Story Quality Test

Before finishing a project page, check:

1. Can the reader understand the project type quickly?
2. Does the page explain the design idea clearly?
3. Does it describe the site/context?
4. Does it describe the user journey?
5. Does it mention materials and atmosphere?
6. Does it explain client value?
7. Does it avoid exaggeration?
8. Does it feel like an architecture publication?
