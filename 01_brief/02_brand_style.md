# Aramphabot Studio — Brand Style Guide

## Brand Keywords

- Quiet Luxury
- Calm Architecture
- Spatial Storytelling
- Contextual Design
- Material Sensitivity
- Refined Proportion
- Warm Minimalism
- Editorial Presentation
- Hospitality Experience
- Architecture of Memory

## Visual Mood

The website should feel like:
- A premium architecture magazine
- A calm design gallery
- A world-class architecture studio portfolio
- A refined hospitality brand
- A thoughtful design journal

## Color Palette

Primary:
- Warm Ivory
- Limestone Beige
- Soft Sand
- Warm Gray
- Charcoal

Accent:
- Muted Bronze
- Deep Brown
- Stone Taupe

Avoid:
- Pure black-heavy design
- Bright corporate blue
- Loud gradients
- Neon colors
- Overly decorative colors

## Typography Direction

Typography should feel:
- Elegant
- Editorial
- Minimal
- Calm
- Professional
- International

Use strong contrast between large headlines and quiet body text.

## Layout Direction

Use:
- Large margins
- Spacious sections
- Strong image grids
- Editorial captions
- Minimal navigation
- Calm transitions
- Clear project storytelling

Avoid:
- Dense layouts
- Too many icons
- Random animation
- Template-like section blocks
