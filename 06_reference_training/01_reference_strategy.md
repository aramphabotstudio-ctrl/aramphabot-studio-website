# Aramphabot Website Reference Strategy

## Purpose

This document teaches Codex how to translate world-class architecture website references into an original website direction for Aramphabot Studio.

Do not copy any website directly. Use the references only as design principles, structural guidance, storytelling guidance, visual mood references, and quality benchmarks.

## Reference Mix

The Aramphabot Studio website should be guided by the following reference formula:

- 60% K-Studio: hospitality storytelling, contextual architecture, project narrative, atmosphere-led portfolio structure
- 20% Norm Architects: calm minimalism, warm materiality, sensory experience, quiet luxury, refined typography
- 10% PHTAA Living Design: Thai contemporary context, local narrative, commercial and hospitality personality
- 10% Foster + Partners: professional credibility, clear project archive, service clarity, corporate trust

## Main Website Character

The website should feel like:

A boutique architecture studio with global hospitality sensibility.

It should combine:
- International presentation quality
- Calm editorial mood
- Warm minimal luxury
- Strong project storytelling
- Contextual and sensory design language
- Clear professional credibility
- Thai contemporary sensitivity
- Real client trust
- Practical clarity for project inquiries

## How to Use K-Studio as a Principle

Use K-Studio as a reference for:
- Hospitality-centered storytelling
- Context-led project descriptions
- Project archive clarity
- Landscape, interior, architecture, and experience integration
- Calm but confident presentation
- Strong visual project sequence

Do not copy:
- Exact layouts
- Exact navigation
- Exact text
- Branding style
- Image treatment one-to-one

## How to Use Norm Architects as a Principle

Use Norm Architects as a reference for:
- Warm minimal mood
- Quiet luxury
- Material atmosphere
- Tactile visual storytelling
- Calm typography
- Editorial composition
- Sensory design language

Do not overuse Scandinavian coldness. Aramphabot should remain warmer, contextual, and connected to Thailand / hospitality.

## How to Use PHTAA as a Principle

Use PHTAA as a reference for:
- Thai contemporary narrative
- Commercial and hospitality character
- Local sensitivity
- Playful but controlled project identity
- Spatial stories connected to culture, site, and use

Do not copy visual identity or specific project language.

## How to Use Foster + Partners as a Principle

Use Foster + Partners as a reference for:
- Professional credibility
- Clear information architecture
- Service clarity
- Well-structured project data
- Corporate trust
- Archive discipline

Do not make Aramphabot feel overly corporate or too large-company generic.

## What to Avoid

Avoid:
- Direct copying of reference websites
- Generic website templates
- Trendy startup design
- Loud animation
- Overly corporate appearance
- Fake awards or fake clients
- Excessive icons
- Overly decorative design
- Heavy black-and-white luxury clichés
- Random gradients
- Unverified claims
- Overly poetic text that does not explain design

## What to Build Instead

Build a website that is:
- Image-led
- Editorial
- Spacious
- Calm
- Premium
- Minimal
- Architectural
- Easy to navigate
- Strong in project storytelling
- Trustworthy for real clients
- Practical enough for business inquiries
- Flexible enough to grow into a serious studio portfolio

## Target Positioning Statement

Aramphabot Studio is a boutique architecture and interior design studio crafting atmosphere-led spaces through context, narrative, material sensitivity, and quiet luxury.

## Final Rule

The website should not look like any reference website. It should look like Aramphabot Studio has learned from the best architecture websites in the world and translated those lessons into its own identity.
